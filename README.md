# TDY Copilot Users

## GitHub Copilot Metrics Collection

GitHub Copilot is an AI-powered code completion tool that Teledyne has invested in to improve developer productivity. As part of our evaluation process, we need to collect usage metrics to measure its effectiveness and return on investment.

## Required Survey

**All GitHub Copilot users are required to complete the usage survey:**

[Complete the GitHub Copilot Survey](../../issues/new?template=copilot-survey.yml)

The survey takes less than 5 minutes to complete and provides valuable data for our ROI calculations.

## Why We Need Your Feedback

- Helps justify the continued investment in developer productivity tools
- Provides insights into how Copilot is being used across different teams
- Identifies opportunities for improving adoption and usage

Thank you for your participation.
